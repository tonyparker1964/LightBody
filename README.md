# LightBody

An offline-friendly, browser-based symbolic 114-point energy-body visualization.

## Run
Open `index.html` in any modern browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Features
- 114 points that illuminate from the feet upward, along the figure and its geometric field
- Full-body artwork with stylized nerves, arteries and veins
- Activate, Pause, Reset, Full Light, speed and brightness controls
- Responsive layout with no external dependencies

## Important
The 114-point model is symbolic, not a medically established chakra atlas. Anatomical lines are artistic rather than diagnostic.
