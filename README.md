# LightBody

An offline-friendly, single-page symbolic 114-point energy-body visualization.

## Run
Open `index.html` in any modern browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Features
- 114 sequential illuminated points and connecting pathways
- Stylized nervous system, arteries and veins
- Activate, Pause, Reset, Full Light, speed and brightness controls
- Responsive layout with no external dependencies

## Important
The 114-point model is symbolic, not a medically established chakra atlas. Anatomical lines are artistic rather than diagnostic. The current repository uses procedurally drawn SVG artwork; the user-supplied rendered image is **not yet included** in this commit.
